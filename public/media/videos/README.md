# Videos

Put MP4 demo clips in this folder and update the matching `src` value in `app/page.tsx`.

Suggested names:

- `1、SWAP_20cm-stair-140cm-gap.mp4`
- `1、SWAP_box-higher_gap.mp4`
- `2、extreme_parkour_gap.mp4`
- `2、extreme_parkour_hurdle.mp4`
- `2、extreme_parkour_step.mp4`
- `3、MOE-CTS Stair.mp4`
- `4、Taylor-IPO.mp4`

For clips that are tens of megabytes, keep them compressed to H.264 MP4 where possible. GitHub has a 100 MB per-file limit; larger files are better hosted on an external video host and linked from the project card.
